# 📦 Project FORESIGHT – AI-Powered Demand & Inventory Intelligence Platform

[![Live App](https://img.shields.io/badge/Live-Demo-success)](https://ai-inventory-intelligence-platform-oksahil45.streamlit.app/)

## Overview

Project FORESIGHT is a Data Science and Analytics project designed to help businesses analyze retail sales data, monitor inventory performance, and generate actionable business insights through interactive dashboards.

The platform leverages Python, Pandas, Plotly, and Streamlit to transform raw retail transaction data into meaningful visualizations and decision-support analytics.

This project demonstrates end-to-end data analytics skills including data cleaning, exploratory data analysis (EDA), business intelligence reporting, inventory monitoring, and dashboard development.

## Installation

### Clone Repository

```bash
git clone https://github.com/oksahil45/AI-Inventory-Intelligence-Platform.git
cd AI-Inventory-Intelligence-Platform
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```

The application will be available at:

```text
http://localhost:8501
```
